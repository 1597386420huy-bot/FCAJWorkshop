### AWS Community Day Vietnam 2026

**Date and time:** Saturday, 21 November 2026, 08:30 – 16:35

**Location:** Hall A1, Hanoi University (HANU), Km9 Nguyen Trai Road, Dai Mo Ward, Hanoi, Vietnam

**Role in the event:** Attendee

**Description of the event:**

AWS Community Day Vietnam 2026 is a free, community-led event with the tagline "Built by the community. For the community." It is organised by the AWS Community Day Vietnam committee with the AWS Vietnam User Group, AWS User Group HCM-DN-HN Vietnam, AWS First Cloud Journey AI and Student Builder Group at UTC, and is sponsored by Cloudino, Amazon Web Services (Diamond) and Hanoi University (Gold).

The programme focuses on AI, security and cost optimisation on AWS, and is organised into the tracks AI, Security, Observability, Cost Optimization and Community. The main activities are:

- Technical talks on cloud architecture, operational lessons and real deployments, from generative AI to DevOps.
- Networking with developers, architects, data and AI practitioners, students and engineers who run production systems.
- Community activities and gifts for attendees.

**Outcomes and value gained:**

- Connect the workshop project (a mobile phone e-commerce application on EC2, RDS, S3, CloudFront, Cognito and CloudWatch) with real-world practice, especially the security (Track 3) and cost optimisation (Track 8) topics.
- Learn how other teams monitor and operate production workloads on AWS (Tracks 4 and 5 on observability), which supports the CloudWatch and clean-up parts of the workshop.
- Build professional contacts with the AWS community and the First Cloud Journey network.
- Practise soft skills: listening to technical presentations, taking notes and asking questions.
